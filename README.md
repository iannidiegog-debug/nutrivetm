# NutriVetM

App PWA para el consultorio nutricional veterinario de Melanie.

## Que incluye esta primera base

- Panel veterinaria.
- Vista tutor.
- Ficha de mascota/paciente.
- Agenda interna.
- Flujo de urgencias con alerta.
- Plan alimentario por etapas.
- Recordatorios.
- FAQ editable.
- Biblioteca de alimentos y recetas.
- Grafico de peso y evolucion.
- Preparacion para Supabase, Firebase, Resend, Vercel, WhatsApp y Google Calendar.
- Login previsto: email y contrasena, con nombre completo y usuario visible en el perfil.
